# 节点订阅 Tab 设计

日期：2026-09-14

## 背景

节点浏览器当前展示所有可连接节点，用户无法快速按订阅来源筛选。希望增加订阅 Tab。

## 目标

- 节点列表上方增加横向可滚动 Tab。
- 第一个 Tab 为“全部”。
- 其余 Tab 为各订阅名称。
- 所有 Tab 等宽。
- 点击 Tab 只显示该订阅下的可连接节点。
- Tab 名称中显示节点统计。

## 非目标

- 不做多级订阅分组。
- 不做 Tab 拖拽排序。
- 不做跨订阅节点合并。

## Tab 规则

- 默认选中“全部”。
- 节点数量显示格式：

```text
全部 99/100
订阅A 12/20
```

- `99/100` 表示：该范围内共 100 个节点，其中 99 个可连接。
- 订阅很多时，Tab 可以横向滑动。

## 数据来源

- 全部：`controller.allNodes`
- 单个订阅：`subscription.nodes`

## 节点过滤

- 所有 Tab 只显示可连接节点。
- 归属地查询和测速基于当前 Tab 的节点列表。

## 页面结构

`NodesScreen`：

1. 头部返回和测速按钮。
2. 订阅 Tab。
3. 当前 Tab 节点列表。

## 错误处理

- 没有订阅时只显示“全部”Tab。
- 订阅名称为空时使用订阅 URL host。
- 单个订阅没有可连接节点时显示空状态。

## 测试方案

### Widget 测试

- 默认选中“全部”。
- Tab 显示数量统计。
- 点击订阅 Tab 后只显示该订阅节点。
- 订阅较多时 Tab 可横向滚动。

## 验收标准

- 节点列表上方显示订阅 Tab。
- 所有 Tab 等宽。
- Tab 可横向滚动。
- 节点统计显示在 Tab 名称中。
- `flutter analyze` 无错误。
- `flutter test` 全部通过。
